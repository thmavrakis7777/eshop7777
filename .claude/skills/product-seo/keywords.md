# Search language — MAVRAKIS HOME keyword map

The owner's rule (2026-11-07): we write in the words Greek shoppers really type, not just text that "sounds right". Many products are searched under two or three names (inox / ανοξείδωτο, καμινέτο / γκαζάκι). Each field gets the term that suits it, and we **don't stamp one pattern on every product**: we decide per category and per product.

## Honest status of this map

We have **no search-volume data** (no Keyword Planner, no Search Console export). The pairs below come from how Greek shops title their listings and how people talk. Treat them as **candidates**, not facts:

- Never write or tell the owner that one term "is searched more" unless real data says so.
- When the owner brings real data (Search Console → Performance → Queries for a page, Google Ads Keyword Planner, Google Trends), update the term's status here and date it.
- Status: `υπόθεση` (assumption, the default) or `επιβεβαιωμένο <date, source>`.

## Which term goes in which field

| Field | What goes in it |
|---|---|
| SEO title | The main commercial term + a key feature (size, material, number of burners) + ` \| MAVRAKIS HOME`, ≤60 chars. A second variant only when it reads as a natural title, like the owner's «Μπρίκι Inox 350ml – Ανοξείδωτο για Ελληνικό Καφέ \| MAVRAKIS HOME» — never «Καμινέτο Γκαζάκι Inox Ανοξείδωτο». |
| H1 | The natural product/category name with the main term. No variants added for SEO. |
| Meta description | The main term **and** one synonym, in a real sentence. ≤155 chars. |
| Description | Every relevant variant **once**, where it reads naturally (e.g. «…το καμινέτο, που πολλοί λένε γκαζάκι…»). Still passes the stuffing check. |
| Slug / URL | Short, one term, no variant lists. Never change a published slug just to add a variant. |
| Alt text | What the product is (unchanged rule). No variant lists. |

**Main term** = the one the shop already uses in the product/category name, unless real data says otherwise. The variant goes in the meta and the description.

**Where the generic synonym lives:** the category page carries the broad synonym (e.g. «γκαζάκια» on Καμινέτα). A product page gets the synonym only when it fits *that* product. Sibling products (same item, other size/colour) must not all get the same sentence — vary it or leave it on one or two.

## Truth rules that beat the map

- **inox / ανοξείδωτο only when the material really is stainless** (DB `material = Ανοξείδωτο` or the owner says so). «Εμφάνιση inox» is a look, not a material (00088). Χρωμέ is not inox. Καμινέτο σχάρες are «ανοξείδωτη» (owner's rule).
- **αντικολλητικό / non-stick only for a real non-stick coating.** Never for enamel (εμαγιέ), cast iron or plain steel.
- A variant must name **the same thing**. If two words are different products in this shop, don't swap them (εταζέρα ≠ ραφιέρα here: they are separate categories; τρόλεϊ is its own thing).
- **Variants that share a noun: write the noun once.** «λάστιχα γκαζιού ή προπανίου», not «λάστιχο γκαζιού ή λάστιχο προπανίου»; «ταινία μπανιέρας ή στεγανοποίησης». Otherwise the stuffing check fails (it did on the first category drafts, 2026-11-07), and the text reads like a keyword list anyway.
- «γκαζάκι» is ambiguous in Greek: it can mean the small stove (καμινέτο) **or** the cartridge (φιαλίδιο). Use it next to the precise word so the meaning is clear.
